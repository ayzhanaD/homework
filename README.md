# Виджет банковских операций клиента

---

## Цель проекта:
Виджет помогает клиенту проверить свои недавние, успешно проведенные банковские операции

---

## Организация виджета:
В проекте находится пять модулей: 
- *masks.py*
- *widget.py*
- *processing.py*
- *generators.py*
- *decorators.py*

---

## Функции модулей:
### masks.py:
- функция `get_mask_card_number` может зашифровать номер карты 
- функция `get_mask_account` может зашифровать номер счета

### widget.py:
- функция `mask_account_card` может определить тип и номер карты, номер счета и вернуть маску карты или счета 
- функция `get_date` преобразует дату в формат: ДД.ММ.ГГГГ

### processing.py:
- функция `filter_by_state` может найти данные по нужному значению ключа 
- функция `sort_by_date` сортирует данные по дате 

### generators.py:
- функция `filter_by_currency` принимает на вход список транзакций 
и возвращает итератор, который поочередно выдает транзакции с заданной валютой
- функция `transaction_descriptions` принимает список транзакций 
и возвращает описание каждой операции по очереди
- функция `card_number_generator` выдает номера банковских карт в формате 
XXXX XXXX XXXX XXXX

### decorators.py:
- функция-декоратор `log` автоматически выводит в консоль начало и конец выполнения функции,
    результат выполнения и возникшие ошибки 

---

## Тестирование функций
Функционал приложения тестируется с помощью фреймворка pytest

### В модуле *masks.py* проверяются два сценария
функций `get_mask_card_numbeк` и `get_mask_account`:
  * если входной номер является строкой 
  * если входной номер является целым числом

### В модуле *widget.py* для проверки функции `mask_account_card`
используется параметризация

В данном модуле также проверяется функция `get_date`

### В модуле *processing.py* проверяется работа функции `filter_by_state`
в двух случаях: 
* состоянию ключа задано значение "EXECUTED"
* состоянию ключа задано значение "CANCELED"

В данном модуле также подается проверке работа функции `sort_by_date`
в двух случаях: 
* при заданном убывающем порядке сортировки 
* при заданном возрастающем порядке сортировки

### В модуле *generators.py* для проверки функции `card_number_generator` 
используется параметризация

В функции `transaction_descriptions` проверяется правильность 
последовательности описаний транзакций

Для проверки функции `filter_by_currency` в тестовых функциях в качестве аргументов
задаются пустой список, присутствующая и отсутствующая валюты

### В модуле *decorators.py* для проверки функции `log` используется четыре сценария:
1. когда функция возвращает ошибку и если задано имя файла, результат выводится в консоль и записывается в файл 
2. когда функция возвращает ошибку и имя файла не задано, результат выводится только в консоль
3. когда функция возвращает время, результат и аргументы, результат записывается в файл, если его имя задано, 
а в консоль выводится сообщение об успешной операции
4. когда функция возвращает время, результат и аргументы, а имя файла не задано, результат выводится только в консоль
